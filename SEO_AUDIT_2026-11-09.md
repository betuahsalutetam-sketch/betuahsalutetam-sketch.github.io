## Masalah & Solusi
- [TINGGI] Tidak ada structured data (Schema.org) seperti LocalBusiness, Organization, atau BreadcrumbList di HTML → Tambahkan JSON-LD structured data untuk LocalBusiness dengan aaddress, phone, email, openingHours, dan areaServed untuk meningkatkan rich snippet di SERP
- [TINGGI] Meta description terpotong sebelum selesai (berakhir di 'ujian onl' bukan 'ujian online') → Perpanjang dan selesaikan meta description dengan call-to-action yang jelas, optimal 150-160 karakter
- [SEDANG] Hanya ada 1 hreflang alternate tag (hanya ke halaman id sendiri), tidak ada variant bahasa atau regional → Jika ekspansi ke region lain direncanakan, tambahkan hreflang yang sesuai untuk Kalimantan Timur atau Indonesia bagian lain
- [SEDANG] Tidak ada internal linking strategy terlihat dari penggalan HTML (hanya link ke about-ahmad-husaini dan external) → Implementasikan internal linking ke halaman penting: daftar program S1/S2, TTM, ujian online, testimoni, dan FAQ UT
- [SEDANG] Open Graph description berbeda dengan meta description - dapat mengurangi konsistensi brand voice → Sinkronisasi pesan di meta description, OG description, dan Twitter description untuk konsistensi messaging
- [RENDAH] Tidak ada breadcrumb visible di HTML snippets yang diberikan → Tambahkan breadcrumb navigation dengan schema markup untuk meningkatkan user experience dan CTR dari SERP
