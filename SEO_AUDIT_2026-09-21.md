## Masalah & Solusi
- [TINGGI] Meta description terpotong/incomplete ('435 ulasan b' tidak lengkap) - hanya menampilkan ~150 karakter di SERP → Lengkapi meta description hingga 155-160 karakter: '...435 ulasan bintang 5 Google. Daftar kuliah S1/S2 UT, TTM, ujian online, tabungan BTN. Layani Balikpapan, Bontang, Kutai Kartanegara.'
- [TINGGI] Struktur H1 tidak terlihat dalam HTML snippet - perlu verifikasi bahwa hanya ada satu H1 per halaman → Pastikan hanya 1 H1 tag di halaman, gunakan format: '<h1>Salut Etam Betuah: SALUT #1 Kalimantan Timur - Mitra Resmi UT Samarinda</h1>'
- [SEDANG] Belum ada Schema.org structured data (LocalBusiness, Organization, FAQSchema) dalam HTML → Tambahkan JSON-LD LocalBusiness schema dengan nama, alamat, telepon, jam operasional, rating/review. Tambahkan FAQSchema untuk pertanyaan umum tentang UT.
- [SEDANG] Meta keywords masih digunakan (sudah tidak relevan untuk ranking di Google modern) → Pertahankan untuk branding, tapi fokus pada konten berkualitas. Keyword sudah bagus, distribusikan dalam konten H2, body text, dan internal links.
- [SEDANG] Belum ada breadcrumb schema atau navigation structured data yang terlihat → Implementasikan BreadcrumbList schema jika ada halaman nested (kategori program, halaman program individual)
- [RENDAH] OG:image dan Twitter:image menggunakan hardcoded path - perlu verifikasi ukuran dan format optimal → Verifikasi og-image.jpg memiliki dimensi 1200x630px, format JPG/PNG, ukuran <200KB untuk loading cepat
